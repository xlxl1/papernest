写作台

粘贴你写好的文稿：润色保留事实与引用编号、逐条给出修改说明；评审按审稿人视角输出总评 / 评分 / 分级问题 / 可执行修改清单，并与库内文献核对引用。

建议先在「文献检索」里勾选与本稿相关的文献——评审会核对文中引用是否站得住；不勾选则按文稿自动检索关联文献。

文献检索与采集

多关键词检索官方学术源（Semantic Scholar / OpenAlex / arXiv），按年份筛选后入库；同一查询二次执行直接走缓存。

上传 PDF

你手上已有的 PDF 也能进库：按内容 sha256 与归一化主键双重去重，按页抽全文，元数据（标题 / DOI / arXiv / 年份 / 摘要）用版面启发式抽取——抽不准的字段如实留空并给出提示，不编造，可在下方逐条修正。

导入 BibTeX / RIS / Zotero CSV

从 Zotero、EndNote、Mendeley 搬家：已存在的按归一化主键跳过，只补空字段、不覆盖已有内容。解析失败的条目单独列出，不会拖垮整个文件。

新论文订阅

从你库里的论文反推「兴趣画像」，给 arXiv 新提交的论文打分。打分确定性、0 次模型调用，每条都说明为什么推给你：命中了画像里哪些词、在标题还是摘要、那个词有没有区分度（批内 IDF）。只命中一个泛词的会被降权并标「弱」。已在库的、最近推过的、你标过「不感兴趣」的都不再出现。
