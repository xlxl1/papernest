# 写作检查点与公式输出

写作任务按章节保存。证据包完成后会写入章节记录；模型生成初稿后立即写入 `raw_content`，检查点为 `draft_saved`；评审失败时保留正文并标记为 `review_pending`。重新运行章节任务会优先读取这个检查点，直接从评审继续，不重复消耗一次生成调用。评审通过后检查点变为 `done`。

网络超时、限流和服务端错误由 LLM 客户端做有限退避；账户欠费、Key 无效和模型不存在等 400 类错误会停止当前步骤并持久化失败原因。证据 Agent 失败时章节仍会记录降级证据包，正文必须标记“待补证据”，不会把未核验内容当作事实。可用章节重生成接口只处理指定章节。

模型输出的公式统一要求使用 LaTeX 分隔符：行内 `\\( ... \\)`，独立公式 `$$ ... $$`。Markdown 导出保留原始 LaTeX；DOCX 导出已接入本地 LaTeX→OMML 转换器，常见分式、上下标、希腊字母和运算符会写成 Word 原生公式对象，MathType 可以继续编辑或导入。遇到未支持的复杂宏时保留原始 LaTeX，避免丢失内容；正式交付仍应做一次 Word/MathType 渲染检查。
